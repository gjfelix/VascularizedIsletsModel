# Vascularized Islets Model

In this repository, you'll find the interactive tool, model files and animations related to the artile "Impact of Vascular Density on Pancreatic Islet Viability: A Computational Study" by Gerardo J. Félix-Martínez, Lizbeth de la Cruz, Daniel Whisman and J. Rafael Godínez-Fernández.

___

This repository contains:
- :computer: An interactive web-based simulation (see `/interactive_tool/index.html`)
- :movie_camera: Animations of the vascularized human and mice islets are found in the `/animations/` folder.
- :paperclip: Model files will be available in the `/models/`folder upon acceptance of the article.


## 🧬 Try the Interactive Tool
👉 [Click here](https://gjfelix.github.io/VascularizedIsletsModel/) to launch the viability model.
